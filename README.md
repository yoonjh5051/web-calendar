# My Calendar

카카오톡 캘린더 스타일의 개인용 셀프호스팅 캘린더입니다.

- **누구나 보기**, **로그인한 관리자만 수정**
- 로그인 페이지는 UI에 노출되지 않음 → `http://localhost/login` 으로 직접 접속
- ICS 파일 가져오기 (구글/애플/아웃룩/카카오톡 캘린더 내보내기 파일) · 내보내기
- **ICS URL 구독**: 지정한 주소를 15분~하루 주기로 자동 동기화
- 일정별 색상 지정 (기본은 캘린더 색상)
- 반복 일정(매일/매주/매월/매년, ICS의 복잡한 RRULE·EXDATE·변경된 회차 포함)
- 여러 캘린더(색상별), 표시/숨김, 검색, 한국 공휴일·대체공휴일 표시
- 모바일 대응 (스와이프로 월 이동, 하단 시트), 다크 모드

## 실행

```bash
cp .env.example .env      # ADMIN_PASSWORD 를 꼭 바꾸세요
docker compose up -d --build
```

- 캘린더: http://localhost
- 로그인: http://localhost/login

데이터는 Docker 볼륨 `calendar-data` 의 `/data/calendar.db` (SQLite) 에 저장됩니다.

### 초기 일정 (seed)

`seed/*.ics` 파일은 **DB가 비어 있는 첫 실행 때만** 자동으로 가져옵니다 (파일 하나당 캘린더 하나).
캘린더 이름은 파일의 `X-WR-CALNAME`, 색상은 `X-APPLE-CALENDAR-COLOR` 를 사용합니다.
이미 데이터가 있는 서버에서는 다시 가져오지 않으므로, 서버 재시작·업데이트 시 중복되지 않습니다.

- `seed/` 의 `.ics` 파일은 개인 일정이므로 **git에 커밋되지 않습니다** (`.gitignore`).
  배포할 서버에서 직접 `seed/` 폴더에 넣은 뒤 빌드하세요.
- 새 서버에 처음부터 다시 받고 싶다면: `docker compose down -v` 로 볼륨을 지운 뒤 `docker compose up -d`
  (**기존 데이터가 모두 삭제되니 주의**)

## 환경 변수 (`.env`)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ADMIN_USERNAME` | `admin` | 관리자 아이디 |
| `ADMIN_PASSWORD` | (없음) | 관리자 비밀번호. 비우면 임시 비밀번호가 컨테이너 로그에 출력됨 |
| `SECRET_KEY` | 자동 생성 | 세션 쿠키 서명 키 |
| `PORT` | `80` | 호스트 포트 |
| `APP_TITLE` | `My Calendar` | 사이트 이름 |
| `PUBLIC_VIEW` | `true` | `false` 면 보기도 로그인 필요 |
| `COOKIE_SECURE` | `false` | HTTPS 리버스 프록시 뒤라면 `true` |
| `APP_TZ` | `Asia/Seoul` | 일정 시간 기준 타임존 |

## 사용법

- 날짜 클릭 → 그날 일정 목록, 일정 클릭 → 상세
- (로그인 시) `일정 추가` 버튼 / 날짜 더블클릭 / `+` 버튼으로 추가, 상세에서 수정·삭제
- 반복 일정 삭제 시 "이 일정만" 또는 "전체" 선택. 수정은 반복 전체에 적용
- ICS 가져오기: 사이드바 → `ICS 파일 가져오기`, 또는 `.ics` 파일을 화면에 끌어다 놓기.
  같은 파일을 다시 가져오면 UID 기준으로 갱신되어 중복되지 않습니다.
- ICS URL 구독: 사이드바 → `ICS URL 구독 추가` 에 `https://` 또는 `webcal://` 주소 입력.
  - 구독 캘린더는 원본을 그대로 따라갑니다 (원본에서 지워진 일정은 여기서도 삭제). 그래서 이 앱에서는 읽기 전용입니다.
  - 주소·주기 변경, 동기화 상태 확인, `지금 동기화` 는 사이드바의 캘린더 편집(연필 아이콘)에서.
  - 구독 URL은 로그인한 관리자에게만 보입니다 (구글 비공개 주소 등 토큰 보호).
  - 구글 캘린더: 설정 → 캘린더 설정 → "iCal 형식의 비공개 주소"
- 단축키: `←` `→` 월 이동, `t` 오늘, `n` 새 일정, `/` 검색, `Esc` 닫기

공휴일은 `app/static/holidays.js` 에 2025–2027년이 들어있습니다. 이후 연도는 직접 추가하세요.

## 구조

```
app/main.py          FastAPI 서버 (인증, 일정/캘린더 API, 반복 일정 전개)
app/ics.py           ICS 가져오기/내보내기
app/static/          프론트엔드 (빌드 없는 바닐라 JS)
seed/                첫 실행 시 가져올 ICS 파일
```
